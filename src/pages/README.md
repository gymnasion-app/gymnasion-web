# Pages

## Overview
Top-level route page components rendered by the React Router configuration in `src/App.tsx`.

## Subdirectories & Boundaries
- SignIn: [./SignIn/README.md](./SignIn/README.md) — Página de login (`/login`) com validação de credenciais, persistência opcional de e-mail lembrado e redirecionamento por perfil (`PERSONAL_TRAINER` vs `ALUNO`).
- StudentProfile: [./StudentProfile/README.md](./StudentProfile/README.md) — Página de perfil detalhado do aluno (`/alunos/:studentId`) com seletor de rotinas ativas, síntese de planejamento secundário, abas (`overview`, `evolution`, `routines`, `history`), registro de sessão e geração de relatório PDF.
- Additional route page directories (`AccountHome`, `Dashboard`, `DesignSystem`, `GroupDetails`, `Groups`, `Home`, `Metrics`, `PasswordRecovery`, `RoutineSessionPlanner`, `Routines`, `Settings`, `SignUp`, `SingUpStudent`, `StravaCallback`, `StudentEvolutionPage`, `StudentSessionDetail`, `StudentSessionEdit`, `StudentWorkouts`, `Students`).
